# 🧊 Cold Chain Guardian: AI-Powered Early Warning System

An end-to-end data pipeline and machine learning framework designed to safeguard sensitive goods in cold storage and supply chains. This system automates raw sensor data ingestion, advanced preprocessing, time-series cleaning, and proactive anomaly detection to ensure optimal temperature compliance.

## 🚀 Key Features
- **Automated Data Pipeline:** Extracts, unzips, and ingests multi-sensor logs seamlessly.
- **Robust Data Cleaning:** Handles missing values, removes redundant headers, and parses complex timestamps.
- **Time-Series Alignment:** Structures and sorts chronological temperature and humidity metrics.
- **Predictive Analytics Ready:** Prepares clean datasets for deep learning forecasting (LSTM/Anomaly Detection).
